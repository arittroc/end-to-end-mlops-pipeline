# House Price Oracle — Indian Tech Hub Markets

## Dataset

The training data is a synthetic 1,000-row dataset of Indian residential properties generated by `generate_data.py`. Pricing is calibrated against real market data from PropTiger and 99acres.

**Pricing model:**
```
price_per_sqft (INR) = city_base × quality_multiplier × year_factor × noise
SalePrice (USD)      = (price_per_sqft × area) / 83
```

| City | Base price/sqft | Median price |
|---|---|---|
| Gurgaon | ₹8,000 | ₹1.67 Cr |
| Bangalore | ₹6,500 | ₹1.18 Cr |
| Kolkata | ₹5,000 | ₹0.66 Cr |

**Feature correlations with SalePrice:**

| Feature | Pearson r |
|---|---|
| GrLivArea | +0.774 |
| OverallQual | +0.543 |
| YearBuilt | +0.281 |
| TotalBsmtSF | +0.072 |

## Pipeline

The ZenML pipeline has three steps:

```
ingest_data_step   →  reads CSV, returns DataFrame (1000 × 6)
clean_data_step    →  IQR outlier removal on GrLivArea + SalePrice (removes ~26 rows)
train_model_step   →  train/test split 80/20, ColumnTransformer + LinearRegression
                       logs metrics to MLflow, registers model in MLflow Registry
```

**Training metrics (HousePriceModel v2):**
- RMSE (log scale): 0.1259
- R²: 0.9513
- RMSE ($): $19,338
- MAE ($): $14,222

## Running Locally

### Prerequisites

- Python 3.10+
- Node.js 20+
- Docker + Docker Compose
- A [Neon.tech](https://neon.tech) PostgreSQL database (free tier works)

### 1. Clone and install

```bash
git clone https://github.com/arittroc/end-to-end-mlops-pipeline.git
cd end-to-end-mlops-pipeline

python -m venv house_price_env
source house_price_env/bin/activate   # Windows: house_price_env\Scripts\activate
pip install -r requirements.txt
```

### 2. Configure environment

```bash
cp .env.example .env
# Fill in your Neon.tech DATABASE_URL and MLflow settings
```

### 3. Start MLflow tracking server

```bash
bash start_mlflow.sh
# Starts MLflow at http://localhost:5055
```

### 4. Register ZenML stack (once)

```bash
zenml integration install mlflow -y

zenml experiment-tracker register house_price_mlflow_tracker \
    --flavor=mlflow \
    --tracking_uri="http://localhost:5055" \
    --tracking_username="user" \
    --tracking_password="password"

zenml artifact-store register local_store --flavor=local

zenml stack register house_price_stack \
    -o default \
    -a local_store \
    -e house_price_mlflow_tracker

zenml stack set house_price_stack
```

### 5. Generate data and train

```bash
python generate_data.py
python run_pipeline.py --data-path data/indian_housing.csv
```

### 6. Register the model in MLflow

```bash
python -c "
import mlflow
mlflow.set_tracking_uri('http://localhost:5055')
client = mlflow.tracking.MlflowClient()
exp = client.get_experiment_by_name('house_price_prediction')
run = client.search_runs([exp.experiment_id], order_by=['start_time DESC'], max_results=1)[0]
v = mlflow.register_model(f'runs:/{run.info.run_id}/model', 'HousePriceModel')
print(f'Registered version {v.version}')
"
```

### 7. Start all services

```bash
docker compose up -d --build
```

## API Reference

### `POST /api/v1/predict`

**Request body:**
```json
{
  "GrLivArea": 1850,
  "OverallQual": 8,
  "Location": "Gurgaon",
  "YearBuilt": 2018,
  "TotalBsmtSF": 0
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `GrLivArea` | int | Yes | Living area in sq ft (> 0) |
| `OverallQual` | int | Yes | Quality rating 1–10 |
| `Location` | str | Yes | `Gurgaon`, `Bangalore`, or `Kolkata` |
| `YearBuilt` | int | No | Construction year (1800–2025) |
| `TotalBsmtSF` | float | No | Basement area in sq ft |

**Response:**
```json
{
  "predicted_price_usd": 287113.94,
  "predicted_price_inr": 23830457.02,
  "predicted_price_formatted": "₹2.38 Cr",
  "model_uri": "models:/HousePriceModel/2"
}
```

### `GET /api/v1/health`

```json
{
  "status": "ok",
  "model_ready": true,
  "version": "1.0.0"
}
```

## Deployment

The `remote_deploy.sh` script syncs the project to a remote server and rebuilds Docker containers:

```bash
bash remote_deploy.sh            # full deploy
bash remote_deploy.sh --dry-run  # preview rsync without transferring
```

The script:
1. Verifies local dependencies (`rsync`, `ssh`)
2. Checks server connectivity
3. Ensures `.env` exists on the server (never synced — create once manually)
4. rsyncs project files (excludes venv, secrets, git history)
5. Runs `docker compose up -d --build` on the server
